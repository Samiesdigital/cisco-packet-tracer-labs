# Lab 04 – DHCP Network Configuration

## Overview
This lab demonstrates the implementation of DHCP services in a Cisco Packet Tracer network.

A DHCP server was configured to automatically assign IPv4 addressing information to network clients. Client devices were configured to obtain their network settings dynamically, and connectivity was tested to verify successful communication.

## Skills Demonstrated
- Cisco Packet Tracer
- DHCP configuration
- IPv4 addressing
- Subnet masks
- Default gateway configuration
- DNS configuration
- Dynamic IP address assignment
- Cisco switch connectivity
- Client/server networking
- ICMP/Ping connectivity testing
- Network troubleshooting

## Configuration and Verification
- Configured a DHCP server with network address pools
- Connected the DHCP server to the Cisco switching infrastructure
- Configured client devices to obtain IP addresses automatically
- Verified successful DHCP address assignment
- Verified default gateway and DNS information
- Tested network connectivity using ICMP ping
