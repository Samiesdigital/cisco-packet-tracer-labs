# Lab 05 – Network Connectivity and DHCP Verification

## Overview
This lab builds on previous Cisco Packet Tracer configurations by configuring and verifying client network connectivity across the simulated network.

Client devices were configured to obtain IPv4 addressing information automatically through DHCP. Network settings were reviewed to verify correct IP address, subnet mask, default gateway, and DNS configuration.

## Skills Demonstrated
- Cisco Packet Tracer
- IPv4 addressing
- DHCP
- Default gateway configuration
- DNS configuration
- Network connectivity
- Client network configuration
- IP configuration verification
- Network troubleshooting

## Configuration and Verification
- Configured client devices for DHCP
- Verified successful DHCP address assignment
- Verified IPv4 address and subnet mask configuration
- Verified default gateway information
- Verified DNS server configuration
- Confirmed client network configuration using Packet Tracer

## Example Client Configuration
- IPv4 Address: 10.0.20.5
- Subnet Mask: 255.255.255.0
- Default Gateway: 10.0.20.1
- DNS Server: 10.0.10.202
